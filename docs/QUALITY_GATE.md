# 质量门与风险定级（QUALITY_GATE）

`quantlab/report.py::quality_gate()` 是唯一放行出口。默认姿态：**不放行，拿证据来换**。

## 1. 复核项与自动不放行条件

| # | 复核项 | 证据 |
|---|---|---|
| 1 | Step 0 五要素齐备 | `config.step0.locked_by_user` + 五项非空 |
| 2 | 数据源与口径标注 | L3 层级 + 前复权 + 跨源校验 + 缺口清单 |
| 3 | 无未来函数 / 代码可运行 | 向后窗口隔离、T+1 撮合、11 项单元测试 |
| 4 | 过拟合四件套 | 样本外 / 参数敏感性 / 蒙特卡洛+DSR / 成本敏感性 |
| 5 | 多重检验校正 | BH-FDR 尝试数、截断值、校正前后显著数 |
| 6 | **合成因子方向一致性** | IC 均值符号；为负即不成立 |
| 7 | 样本外未显著劣化 | 样本内外夏普对比 + 使用次数 |
| 8 | 容量评估 | `capital=null` → 存疑，不输出容量结论 |
| 9 | 数据缺口已登记 | `config.data.known_gaps` + 风险表 |
| 10 | 风险定级 IF_RISK 契约 | 重大/较大条目均含触发条件 + 具体动作 |
| 11 | 合规声明与配色 | 6 条声明 + 红涨绿跌 |
| 12 | 策略级投资结论 | 演示样本非全 A → 不成立 |

自动不放行：五要素缺失、四件套缺项、数据不可得却笃定结论、容量未评估却给规模建议、出现荐股/买卖点/目标价/收益承诺、缺合规声明、高风险缺具体 IF_RISK。

## 2. 本次实测的裁决要点（2026-11-16）

事实（来自 `output/result.json`，样本区间 2018-01-02 ~ 2026-11-13、成本假设见 Step 0）：

- 合成因子 IC 均值 **-0.0838**（t=-13.62，正 IC 占比 38.1%），6 个单因子 IC 均值**全部为负** → 方向反转，**不成立**。
- 样本内夏普 **0.6106** → 样本外（2024-01-01 起）夏普 **-0.2065**，样本外使用次数 1 → **存疑**。
- 蒙特卡洛随机对照：200 条路径，随机夏普均值 0.5932，基准 0.4422 仅处 **8.5 分位**；Deflated Sharpe **0.170**（54 次试验）→ 策略不优于随机选股。
- 成本 ×3 后总收益仍为正（0.4955），但成本占毛收益 **12.86%**；冲击成本按设定未建模。
- 参数网格夏普极差 0.5664，无悬崖式衰减。
- 容量未评估（用户选择「仅研究、不设规模」）→ **存疑**。
- 重大级数据缺口：全 A PIT 面板缺失 → 未决。

**结论**：最终判定 **不放行**；工程与方法**修复后复核可交付**，策略级投资结论**不放行**。本次交付的是可复现的研究框架，不是可实盘的策略。

> 复核项数量与成立/不成立/存疑计数**不再手写**：以 `output/result.json` 的 `quality_gate.counts` 为唯一基准，由 `report.py::quality_gate()` 逐条推导（v1 曾因手写「成立 7 / 不成立 3 / 存疑 2」与实际 8/2/2 不符，已由专家团审核发现并改为自动渲染）。

## 3. 风险定级汇总表

| 要素 | 定级 | IF_RISK（触发 → 动作） |
|---|---|---|
| 合成因子方向一致性 | 重大 | IC<0 → 立即冻结权重组合，禁止继续调参；全 A PIT 面板重估方向 |
| 数据缺口（幸存者偏差/行业/ST/PIT） | 重大 | 未补齐前所有绩效数字仅作引擎验证，不得作为策略有效性证据 |
| 样本外表现 | 较大 | 样本外夏普低于样本内 50% → 冻结参数，回 Step 1 重做因子检验 |
| 多重检验后因子显著性 | 重大 | 显著但方向为负 → 禁止写「有效因子」，重新检验方向 |
| 成本完整性 | 较大 | 成本×2 归零 → 降频或扩持仓数；接入规模前补冲击成本曲线 |
| 容量评估 | 较大 | 给出规模与参与率后补容量上限，未补齐前禁止规模建议 |
| 参数敏感性 / 四件套完整性 | 一般 | 极差>0.8 → 改区间共识参数；样本外使用>3 次 → 结论降存疑 |
| 合规与表述 | 提示 | 无 |

## 4. 交付后必须跟进

1. 在**全 A 点时间面板**上重估 6 个因子的 IC 符号，决定反向使用还是弃用当前权重组合。
2. 补齐退市股 / 历史 ST / 行业分类 / PIT 财务，重跑全流程。
3. 给出资金规模与单标的参与率上限，补冲击成本曲线与容量上限。
4. 样本外仅使用 1 次；后续任何回改参数行为须递增 `oos_use_count` 并重新定级。
5. 每季度复检 IC 衰减、拥挤度与参数敏感性。
