`quantlab/report.py::quality_gate()` 是唯一放行出口。默认姿态：**不放行，拿证据来换**。

## 2. 本次实测的裁决要点（v3 · 2026-11-16）

事实（来自 `output/result.json`，样本区间 2018-01-02 ~ 2026-11-13、成本假设见 Step 0）。
**关键读数不在此手写**：完整基准见自动渲染的 `docs/metrics.md`，`python -m quantlab verify` 会抓任何漂移。

- 合成因子 IC 均值 **-0.083828**（HAC t=-4.2447；iid t=-13.6191 仅列作对照），6 个单因子 IC 均值全部为负 → 方向反转，**不成立**（硬否决）。
- 样本内夏普 **0.7708** → 样本外（2024-01-01 起）夏普 **-0.7933** → **不成立**；样本外使用次数 1，已由 `state/research_state.json` 持久化。
- **等价随机对照**：复用完整权重函数 / 择时 / 熔断 / 两段式撮合，200 次真实引擎重跑，真实 score 重跑与基准逐日净值差 0.0、成本差 0.0。基准夏普 **0.3477** 仅排 **31.5 分位**，随机均值 **0.3748**，DSR **0.080319**（90 次试验）→ **未显著优于随机**（硬否决，替代原「等价性」否决）。
- 多重检验：BH-FDR 尝试数分母 **90**（6 因子 × 15 组真实网格），与 DSR `n_trials` 一致；校正后显著 2 个，但显著≠方向正确。
- 参数敏感性：7 轴 15 组单轴扰动，夏普极差 0.3656，邻域共识夏普 0.3477，单点-共识差 0.0 → 无悬崖衰减、无点估计嫌疑。
- 风险收益比：最大回撤 **-0.601866** / Calmar **0.0837** / 峰度 **12.9232** / 夏普 0.3477（rf=0）→ **不成立**，这是不可通过补数据消除的实盘否决项（硬否决）。
- 撮合与会计：现金最低 ¥0.00、最大持仓敞口 1.0000、被拒订单 7 笔留痕 6 项；25 项单测全通过 → **成立**。
- 系统性 beta 0.434 / R² 0.3654；容量 `not_evaluated`（capital=null）；双价格口径仅完成涨跌停基准 → 两条 **存疑**。
- 重大级数据缺口：全 A PIT 面板缺失 → 未决。

**结论**：最终判定 **不放行**（成立 16 / 不成立 5 / 存疑 2）；工程 **可交付**，策略级投资结论 **不放行**。
硬否决 4 条：合成因子方向一致性、随机对照显著性、风险收益比与尾部风险、策略级投资结论。
本次交付的是可复现的研究框架，不是可实盘的策略。

> 复核项数量与成立/不成立/存疑计数以 `output/result.json` 的 `quality_gate.counts` 为唯一基准，由 `report.py::quality_gate()` 逐条推导；两票与 final 均由真实读数、进程内自检与断言结果反推，不硬编码。

## 3. 风险定级汇总表

| 要素 | 定级 | IF_RISK（触发 → 动作） |
|---|---|---|
| 合成因子方向一致性 | 重大 | IC<0 → 立即冻结权重组合，禁止继续调参；全 A PIT 面板重估方向 |
| 数据缺口（幸存者偏差/行业/ST/PIT） | 重大 | 未补齐前所有绩效数字仅作引擎验证，不得作为策略有效性证据 |
| 样本外表现 | 较大 | 样本外夏普低于样本内 50% → 冻结参数，回 Step 1 重做因子检验 |
| 多重检验后因子显著性 | 重大 | 显著但方向为负 → 禁止写「有效因子」，重新检验方向 |
| 风险收益比与尾部风险 | 重大 | MDD<-30% 或 Calmar<0.5 → 判定为不可通过补数据消除的实盘否决项 |
| 成本完整性 | 较大 | 成本×2 归零 → 降频或扩持仓数；接入规模前补冲击成本曲线 |
| 容量评估 | 较大 | 给出规模与参与率后自动算容量上限，未补齐前禁止规模建议 |
| 系统性 beta 暴露 | 较大 | beta>0.5 且 R²>0.5 → 列独立压力情景；接入真实宽基指数后重估 |
| 停牌 / 跌停无法止损 | 较大 | 任一标的连续 2 日不可卖 → 人工复核并给退出预案，计入尾部 |
| 流动性与容量 | 较大 | participation>10% → 逐标的检查越限项，补真实成交额后重算 |
| 参数敏感性 / 四件套完整性 | 一般 | 极差>0.8 或单点高于共识>0.15 → 改区间共识参数；样本外使用>3 次 → 降级 |
| 合规与表述 | 提示 | 无 |

## 4. 交付后必须跟进

以下为 `quality_gate.followups` 的当前 7 项，均为**依赖外部数据、用户输入或新研究假设**的未决项；工程侧可闭环部分已全部落地（见 `docs/DEVELOPMENT_v3.md`）。

1. 冻结当前合成得分权重组合，补齐全 A 点时间面板前禁止反向使用或继续调参。
2. 接入含退市股 / 历史 ST / 历史行业 / PIT 财务 / 真实成交额的全 A 点时间面板后重跑 IC / FDR / 分层。
3. 给出 `step0.capital` 与真实成交额，产出参与率明细、冲击成本曲线与容量上限（计算路径已实现，缺输入）。
4. 补除权除息流水，把成交价也切到未复权口径并同步现金 / 分红。
5. 把单轴扰动扩为含交互项的全因子设计，增加独立验证段与调仓频率轴。
6. 把等价随机对照扩展到「换因子定义」的研究者自由度。
7. 接入真实宽基指数替换等权样本指数，重估 beta 与 MA200 择时。
