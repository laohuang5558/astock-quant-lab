# 策略规格（STRATEGY_SPEC）

## 1. Step 0 基线（用户锁定，见 config/default.json）

| 项 | 值 |
|---|---|
| 标的池 | 全 A 股，剔除 ST / 退市 / 上市不足 120 日；演示样本 = 20 只真实 A 股 |
| 频率 | 日频信号 + 月末调仓 |
| 资金规模 | `null`（仅研究，不设规模）；记账单位 ¥1,000,000 仅用于最低佣金与份额计算 |
| 区间 | 2018-01-01 ~ 2026-11-13，样本外自 2024-01-01 |
| 成本 | 佣金 2.5bp 双边（最低 ¥5）、印花税 10bp 仅卖出、滑点 5bp、冲击成本 `none` |
| 杠杆做空 | 关闭，`max_leverage=1.0`，`short=false` |

## 2. 因子定义

全部由 OHLCV 计算，不依赖财务数据，因此**不存在财报可得时点问题**。

| 因子 | 公式 | 方向 | 权重 | 说明 |
|---|---|---|---|---|
| `mom_60` | `close.shift(5)/close.shift(65) - 1` | 高为好 | 0.25 | 跳过最近 5 日，规避短期反转污染 |
| `mom_120` | `close.shift(5)/close.shift(125) - 1` | 高为好 | 0.15 | 中长期动量 |
| `rev_5` | `-(close/close.shift(5) - 1)` | 高为好 | 0.15 | 5 日反转（已取负号） |
| `low_vol_20` | `-std(daily_ret, 20)` | 高为好 | 0.15 | 低波动异象 |
| `liq_20` | `log(mean(amount, 20))` | 高为好 | 0.15 | 流动性；amount 为近似值 |
| `illiq_20` | `-mean(|ret|/amount, 20)` | 高为好 | 0.15 | 负 Amihud 非流动性 |

**预处理链**：横截面 MAD 去极值 → 百分位排名 → Z-score → （行业数据可得时）行业内去均值 → 加权求和 → 再标准化 → 用 `eligible` 掩码剔除不可交易标的。有效标的不足 `factors.min_cross_section` 的截面整行置 NaN，不插值。

v3 起，去极值（`factors.winsor`）、标准化（`factors.standardize`）、缺失截面策略（`factors.nan_policy`）全部由配置驱动，非法取值直接报错，`audit.config_wiring` 逐项声明是否接线。`FACTOR_META.sign` 虽然接线，但预注册方向**全部锁为 +1**；禁止依据本样本 IC 为负就反号，那属于用样本外信息回改假设。

**统计口径**：IC 序列使用 20 日重叠前向收益，显著性必须用 Newey-West / Bartlett HAC 调整的 t 统计量（`overlap_lags=20`），同时保留 iid t 作对照；BH-FDR 的分母用**尝试数**（由真实 `validation.sensitivity_axes` 推导，与 DSR 的 `n_trials` 同源），不是最终 p 值个数。

**财务因子插件（未启用）**：EP / BP / ROE 需要 `report_date` + `publish_date` 的 PIT 面板；当前数据源不覆盖，故不产出这些因子，也不伪造数值。

## 3. 信号合成与过滤

1. `score = Σ w_i · z_i`，权重见上表，等权/IC 加权/最优化为插件位。
2. **个股趋势过滤**：`close > MA60` 且 `MA60 > MA120`，两者都为真才进入候选。
3. **大盘择时**：由 `strategy.market_timing.proxy` 驱动，当前为等权样本指数（生产应替换为中证全指）；在其 MA200 之上 → 敞口 1.0；之下 → 敞口 0.5。`proxy` 取非法值直接 `ValueError`，不静默回退。
4. **回撤熔断**：净值回撤 ≥15% → 敞口 ×0.5；≥20% → 敞口 0（清仓）；回撤收敛到 ≤8% 才恢复。档位**可从任意档位逐级升档**，清仓档用「影子净值」（等权样本指数日收益复利）判断恢复，避免现金状态锁定；敞口变化**当日强制生成新目标、T+1 开盘生效**，不再等月末。熔断事件记录 `trigger_date` / `effective_date` 并写入报告。
5. **行业权重上限**：`strategy.max_industry_weight` 已接线；行业标签缺失时不生效并登记为缺口。当前样本行业分类缺失，该约束未产生实际裁剪。

## 4. 组合权重与调仓

| 约束 | 值（演示样本） | 生产建议 |
|---|---|---|
| 持仓数 `top_n` | 8 | 30~50（全 A） |
| 单标的上限 | 20% | 5% |
| 行业上限 | 40%（本次未生效，行业数据缺失） | 30% |
| 单期换手上限 | 60% | 30%~50% |
| buffer | 旧持仓若仍在 Top 1.5N 内则优先保留 | 同 |
| 调仓日 | 每月最后一个交易日收盘出信号 | 同 |
| 执行 | T+1 开盘价 ± 滑点 | 同 |

`_cap_weights()` 用迭代裁剪保证单标的上限；换手超限时与上期权重线性混合。`_cap_industry_weights()` 在行业上限裁剪后**不再做全局归一化**：若行业数不足以支撑满仓，组合总权重 <1，剩余留现金，而不是把权重重新推回超限额。该行为由单测构造性覆盖（约束不可行时不得违反上限）。

## 5. 回测撮合口径

- **成交价**：T+1 开盘价（前复权口径），买入 `open×(1+slip)`，卖出 `open×(1-slip)`。涨跌停基准用未复权前收/开盘，成交价仍前复权——除权除息流水缺失，故只做半步，见 `DATA_CONTRACT.md`。
- **不可成交**：开盘价 ≥ 涨停价不可买；≤ 跌停价不可卖；无开盘价/停牌跳过。涨停比例按板块 10%（主板）/ 20%（创业板 688/300）/ 30%（北交所），ST 直接剔除。被拒订单登记 `unfilled_history` 并在下一个 pending 日重试，不静默丢弃。
- **两段式撮合**：先卖后买，买入按可用现金等比例缩放；逐日断言 `cash >= -1e-6`、`exposure <= 1.0 + 1e-6`，与「纯多头、无杠杆」一致（v1 的负现金/隐性杠杆缺陷已废止）。
- **T+1**：按持仓批次 `lots` FIFO 记录买入日，卖出只消耗 `buy_date < 当日` 的份额。早期 `bought_today` 为 dead code，已删除，不得再作为 T+1 实现依据。
- **成本**：佣金 `max(gross×2.5bp, ¥5)`；卖出加 `gross×10bp` 印花税；滑点单独记账；费率全部来自 `config.cost`，代码零硬编码。
- **盯市**：收盘价（缺失则用最近前收），份额允许小数。
- **成本占毛收益**：`cost_total / (net_pnl + cost_total)`，毛收益 ≤0 时明确标注「不适用」。

## 6. 过拟合检验四件套（缺一不放行）

1. **样本外 + 预注册**：2024-01-01 切分；`state/research_state.json` 持久化冻结假设哈希与策略参数指纹，记录 `oos_use_count`。任何回改参数指纹变化都会自动递增计数，超过 `validation.oos_max_uses` 即降级；`python -m quantlab preregister --force` 是唯一改写入口。禁止据样本反号或换因子定义后仍声称「样本外只用过一次」。
2. **参数敏感性**：`validation.sensitivity_axes` 定义 7 条轴（持仓数、趋势长窗、择时窗、单标的上限、因子权重、熔断恢复阈值、滑点），采用**单轴扰动**而非全组合穷举；输出邻域共识夏普、点估计与共识之差、夏普极差与悬崖式衰减判定。核对基准点是否只是邻域中的幸运抽样。
3. **等价随机对照 / Deflated Sharpe**：`mc_paths` 次随机 score 对照**完整复用 `build_weight_function`、趋势/择时/熔断、两段式撮合**，只替换选股得分；先用真实 score 经 `score_override` 重跑，断言逐日净值与总成本逐值一致（`control_equivalence`）后才计算基准分位。DSR 用 Bailey & López de Prado 近似式，`n_trials` 由真实参数网格 × 因子数推导，**与 BH-FDR 的 `n_attempted` 同源**。等价性不成立时分位与 DSR 直接置空，不给结论。
4. **成本敏感性**：成本倍数由 `validation.cost_multipliers` 驱动，检查总收益是否归零；成本项来自配置，不得在代码中另设费率。

四件套的完整性由 `analytics.overfit_suite()` 判定，且要求 `control_equivalence=True` 才算 complete；任一缺项写 `None` + 原因，不得以占位值补齐。当前读数见 `output/result.json` 与 `docs/metrics.md`。

## 7. 风险模型

- **仓位**：纯多头、目标满仓（受择时与熔断缩放），无保证金与穿仓边界。
- **止损**：采用组合级回撤熔断，不设个股固定止损（避免与月度调仓冲突）。
- **尾部**：历史模拟法 VaR / CVaR（95%、99%）。
- **压力测试**：历史情景（2018 / 2020H1 / 2022 / 2024，样本未覆盖则写「未覆盖」）+ 假设情景（相关性跳升、流动性枯竭、连续跌停、择时失效），两栏分列，假设情景明确标注为模型估计。
- **相关性**：全样本 vs 最差 40 日的平均两两相关，检验极端行情是否跳升。
- **系统性 beta（v3）**：组合日收益对等权样本指数日收益的 OLS beta 与 R²；指数为代理口径，折损已登记。
- **无法止损（v3）**：停牌 / 跌停导致卖出订单被拒，登记 `unfilled_orders` 与 carry 重试，作为独立风险项定级，不与回撤熔断混为一谈。
- **流动性与容量（v3）**：`capacity_report()` 在 `step0.capital=null` 时显式输出 `not_evaluated`；给出资金规模后按参与率上限、线性冲击假设与 ADV20 估算容量上限。冲击系数为**显式假设而非实测**，成交额为近似值，结论必须标注「模型估计」。
- **风险收益比与尾部（v3）**：夏普/卡玛、峰度、历史 VaR/CVaR、压力情景共同进入 `audit.risk_pricing`；不达标直接构成质量门硬否决。

## 8. 失效条件

- 因子 IC 连续 2 个季度 <0.03 或 BH-FDR 校正后无显著因子 → 停用合成得分。
- 合成因子 IC 方向为负且与预注册方向相反 → 不得据样本反号，直接判方向不成立。
- 样本外夏普低于样本内 50% → 冻结参数并回到因子检验。
- 等价随机对照下基准**未显著优于随机**（低于随机 P95），或 `control_equivalence` 不成立 → 策略级结论不放行。
- 参数邻域出现悬崖式衰减，或点估计显著偏离邻域共识 → 改用区间共识参数。
- 成本倍数放大后总收益归零 → 先降频或扩持仓数。
- 样本外使用次数超过 `oos_max_uses` → 结论降「存疑」，须另设独立验证段。
- 接入资金规模后若「目标规模 ÷ 容量上限」>30% → 至少定级「较大」，>50% 定级「重大」。

## 9. 质量门与合规

`report.quality_gate()` 是唯一放行出口，工程票与策略票分开给出。当前 v3 的裁决、硬否决项、未决 followups 与全部读数见 `output/result.json`、`docs/QUALITY_GATE.md` 与 `docs/metrics.md`；本规格文档不转录绩效数字，避免口径漂移。数值变动后必须重跑完整流水线、重建两份 HTML 报告并执行 `python -m quantlab verify --render`。

**合规**：research-only，不含实盘下单、券商接口、自动交易循环；不荐股、不给买卖点与目标价、不承诺收益、不代操作。回测结果不等于实盘表现，历史业绩不代表未来。
